# AlgoLab

A Next.js practice site for data structures and algorithms. Browse 12 problems by topic and difficulty, open a problem, and implement its JavaScript `solve` function.

- **Run code** checks the examples. **Submit solution** checks the full test set and records a solve.
- Drafts, bookmarks, and progress are saved in this browser.
- The JavaScript runner executes in a sandboxed iframe and a disposable worker with a three-second timeout.

## Run locally

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run build` to create the static site in `out/`.
